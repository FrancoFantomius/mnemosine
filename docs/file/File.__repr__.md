# `mnemosine.file.File.__repr__`

**Kind:** method

## Signature

```python
File.__repr__(self)
```

## Documentation

A short, readable representation of the file.


**Returns:**
- `str`: `<File id='...' name='...' sha256=...>`.


**Example:**

```python
>>> f
<File id='01G...' name='a.txt' sha256=...>
```
